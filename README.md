# Dovednosti nenásilné komunikace (dovednosti.ink.cz)

Statická PWA bez build kroku. Karty dovedností INK: procházení po sekcích, označení vlastní úrovně (1–4), uloženo jen v telefonu.

- `data.js` – veškerý obsah (sekce, 44 karet, 4 úrovně)
- `app.js`, `style.css`, `index.html` – aplikace
- `sw.js` – offline režim; při každé změně zvýšit `VERSION`
- `CNAME` – dovednosti.ink.cz
